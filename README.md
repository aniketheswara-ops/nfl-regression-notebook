# What Wins in the NFL? Linear and Logistic Regression with Real NFL Data

A student notebook that teaches regression using NFL data from [nflverse](https://github.com/nflverse).

**Open in Colab:** https://colab.research.google.com/github/aniketheswara-ops/nfl-regression-notebook/blob/main/NFL_Regression_Student_Notebook.ipynb

## What's inside
| Part | Topic | Method |
|---|---|---|
| 1–2 | Building and exploring a team-season dataset (2010–2025) | data cleaning, correlation |
| 3 | One stat, one line | simple linear regression |
| 4 | Offense and defense models, tested on unseen seasons | multiple linear regression |
| 5 | From points to wins | regression on win % |
| 6 | Win probability built from scratch | counting → logistic regression, interactions |
| 7 | The most important plays of 2025 | win-probability swings from our own model |
| 8 | The 2026 season so far | applying the models |
| 9 | Limitations and exercises | |

## How to run
Open the Colab link and choose **Runtime → Run all** (about 3 minutes). Data downloads automatically.
